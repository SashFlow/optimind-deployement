OptiMind lets you configure AI voice agents, run web or phone sessions, and extend the agent with tools and mid-session capture flows.

## Next steps

1. Configure an agent under **Call Session** (modalities, proctoring, OTP input).
2. Attach Python tools for ID, face, or OTP capture when needed.
3. Read the [worker contract](/docs/sessions/worker-contract) if you maintain an external LiveKit agent worker.
